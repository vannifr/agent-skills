# Prepare a First-Impression Test

## Background

`inputs/` holds the brand card of a small mediation practice and a note
with the live URL and the languages of its site. The owner wants to know
what a visitor understands in the first seconds. You can launch read-only
subagents and a browser, but in this task you only prepare the run.

## Task

Write `RUN-PLAN.md`: the screenshots and measurements you would take, the
complete prompts you would give to each subagent (written out in full, as
a subagent does not see this conversation), the order of the steps, and
how you would use the results afterwards.
