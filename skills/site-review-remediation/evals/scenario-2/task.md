# Close Out the Northwind Gatherings Remediation

## Background

An agent has been reviewing and fixing the Northwind Gatherings website. Its session log is in `inputs/session-log.md`. The owner set a goal that everything must be live validated, and now asks for the final status so they can decide what to do next.

You cannot run any commands against production or the repository from here. Work only from the log.

## Your Task

Write `docs/final-status.md` for the owner. It must give, per item in the log:

- the status: fixed and live validated, fixed but not yet live validated, handed back to the owner, or not changed;
- the evidence the status rests on;
- for anything not finished, the exact action the owner must take (command or step), and what you will do once they have done it.

Also state clearly whether the owner's goal has been met.
